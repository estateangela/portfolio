01 // ABOUT

who / what / how

◇ PROFILE

QA engineer building QA × AI. ~2 years in crypto/fintech QA, a domain that doesn't forgive: KYC/AML, Travel Rule, on-chain transfers and financial reconciliation must be correct, not just "green".

I built an AI-assisted API testing tool now part of the team's regression flow — turning my own workflow into something reusable, so quality lives in tooling and documented domain knowledge instead of one person's head.

I also design (Figma) and build (Flutter / React), so I catch problems from both sides — how it looks and how it breaks — and shrink the gap between design, dev and QA.

Curious, detail-obsessed, and always automating the boring parts. I care less about "it passed" and more about "we understand why."
